# Public research data

Commit data only when it is reasonably sized, mathematically relevant, lawful
to redistribute, and reproducible. For every dataset record:

- generating script and exact command;
- code and dependency revision;
- parameter domain and included families;
- schema and mathematical meaning;
- integrity hash;
- how the data is verified or consumed;
- why it belongs in the public repository.

Large, private, licensed, diagnostic-only, or readily regenerated artifacts do
not belong here.
